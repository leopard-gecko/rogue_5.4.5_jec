Rogue 5.4.5jec.056  Windows版
================================

Rogueは1980年頃に誕生した、文字や記号で描かれる迷宮を探索する
コンピューターRPGです。プレイヤーは怪物と戦い、さまざまな道具を
駆使しながら、迷宮の奥に隠された「イェンダーの魔除け」を探します。

Rogueは、現在「ローグライク」と呼ばれるゲームの元祖としても
知られています。Rogue 5.4は、その元祖Rogueの最終バージョンです。
プレイするたびに姿を変える迷宮、効果を探りながら使いこなす
さまざまな道具、一つひとつの判断が冒険の行方を左右する緊張感など、
今でも色あせない魅力を持っています。

このパッケージはWindows 10 / 11（64ビット）向けの
Rogue 5.4.5jec.056です。Rogue 5.4のゲーム内容を基本的にそのままに、
日本語・英語の切り替え、日本語や絵文字の入力、カラー表示、
アニメーションを再現する表示遅延、現代のOSへの対応を加えています。
カラー表示と、識別の巻き物を1種類にするオプションは、
Y.Oz Voxさんが公開しているRogue 5.4.5pから移植しています。

【同梱ファイル】

  rogue.exe             通常版
  rogue_original.exe    オリジナル設定版
  rogue_ja.html         【運命の洞窟】への案内書（日本語）
  rogue_en.html         【運命の洞窟】への案内書（英語）
  LICENSE.txt           著作権・ライセンス
  README_ja.txt         このファイル
  README_en.txt         英語のREADME

通常版とオリジナル設定版は共通のゲームプログラムを使用していますが、
言語やカラー表示、識別の巻き物などの初期設定が異なります。
通常版は遊びやすさを重視した設定で、オリジナル設定版は元のRogue 5.4に
近い表示・操作設定を使用し、英語表示で起動します。どちらもゲーム中に
日本語と英語を切り替えることができます。

　項目　　　　　　　　　　　　　　　通常版　　　　　　　オリジナル設定版
  ----------------------------------------------------------------------------
　初期表示言語　　　　　　　　　　　OSの設定から選択　　英語
　カラー表示　　　　　　　　　　　　有効　　　　　　　　無効
　通路の角で自動移動　　　　　　　　有効　　　　　　　　無効
　識別の巻き物を１種類にする　　　　有効　　　　　　　　無効
　カーソル表示　　　　　　　　　　　無効　　　　　　　　有効

カラー・移動・カーソルなどの設定は、ゲーム中のオプション画面でも
変更できます。元のRogue 5.4には識別の巻き物が5種類ありますが、
通常版では1種類にまとめる設定（idscrl）が有効になっています。
この設定はゲーム開始後には変更できません。

【起動方法】

1. ZIPファイルを任意のフォルダーに展開してください。
   セーブデータを保存できる、書き込み可能な場所を推奨します。
   （例：C:\Games\Rogue）

2. エクスプローラーから起動する場合は、通常版ならrogue.exe、
   オリジナル設定版ならrogue_original.exeをダブルクリックします。

   既定のセーブファイルがある場合は、次のメニューが表示されます。

     [R/Enter] セーブした冒険を再開する
     [N]       新しい冒険を始める
     [F]       別のセーブファイルを選ぶ
     [Q]       終了する

   セーブファイルがなければ、メニューなしで新しいゲームが始まります。
   [F]ではWindowsのファイル選択画面が開き、キャンセルすると
   メニューに戻ります。新しい冒険を始めても既存のセーブファイルは
   削除されません。

3. セーブファイルをrogue.exe（またはrogue_original.exe）に
   ドラッグ＆ドロップすると、そのファイルから直接再開できます。

4. ターミナルから起動するには、展開先フォルダーを開き、
   Windows 11なら右クリックして「ターミナルで開く」を選びます。
   この項目がない場合は、フォルダーのアドレスバーにpowershellと
   入力してEnterを押してください。起動するコマンドは次のとおりです。

   通常版：
       .\rogue.exe

   オリジナル設定版：
       .\rogue_original.exe

   コマンドプロンプト（cmd.exe）からも起動できます。
   ターミナルから引数なしで起動した場合は、新しいゲームが始まります。

端末は80列×24行以上でご利用ください。ゲームの描画範囲は80×24に
固定されています。ダブルクリック起動時には、
Windows TerminalやConsole Hostのウィンドウを80×24に調整する
処理が働きますが、表示環境によっては調整されない場合もあります。
既に開いているターミナルから起動した場合、サイズは変更しません。

ゲーム中に「!」を入力すると、Windowsのコマンドプロンプトを開くことが
できます。「exit」で終了するとゲームに戻ります。

【セーブデータとスコア】

プレイ中の保存操作でセーブファイルを作成できます。
ターミナルから既定のセーブファイルを再開する場合：

       .\rogue.exe -r

別の名前・場所のセーブファイルを指定する場合：

       .\rogue.exe "保存ファイル名"

スコア一覧だけを表示する場合：

       .\rogue.exe -s

墓標を表示し、スコアへの登録を試みる場合：

       .\rogue.exe -d

オリジナル設定版では、rogue.exeをrogue_original.exeに
置き換えてください。正常にゲームを再開すると、元のセーブファイルは
削除される仕様です。必要なデータは事前にコピーしておいてください。

通常版とオリジナル設定版は、次の既定ファイル名を共通で使用します。

  セーブファイル         rogue.save
  スコアファイル         rogue.scr

これらは通常、起動時の作業フォルダーに作られます。エクスプローラー
から直接起動した場合は、通常、実行ファイルのあるフォルダーです。
同じセーブデータから再開でき、スコアも共通です。同じセーブファイルを
複数のゲームで同時に使用することは避けてください。

ROGUEOPTSのfile=で既定のセーブファイル名を変更できます。

【Windowsでの環境変数の設定】

起動時の設定には環境変数ROGUEOPTSを使用できます。
設定項目の意味は同梱の案内書の「オプション」をご覧ください。
ここではWindowsで設定する方法だけを説明します。

PowerShellで一時的に設定する例：

       $env:ROGUEOPTS = "name=勇者,language=ja"
       .\rogue.exe

コマンドプロンプト（cmd.exe）での例：

       set "ROGUEOPTS=name=勇者,language=ja"
       rogue.exe

これらの指定は、その端末とそこから起動したプログラムに有効です。
エクスプローラーからのダブルクリックには引き継がれません。

常に同じ設定で遊びたい場合は、Windowsのユーザー環境変数へ登録します。

  1. Win + Rで「ファイル名を指定して実行」を開き、sysdm.cplを実行。
  2. 「詳細設定」→「環境変数」を開く。
  3. 「ユーザー環境変数」で「新規」を選ぶ（既存なら「編集」）。
  4. 変数名にROGUEOPTS、変数値に設定文字列を入力する。
  5. 「OK」で保存する。反映されない場合はWindowsに再サインインする。

設定をやめるときは、登録したユーザー環境変数を削除してください。

【遊び方とライセンス】

操作方法、画面の見方、コマンド、アイテム、オプションの説明は、
同梱の『【運命の洞窟】への案内書』（rogue_ja.html / rogue_en.html）を
ブラウザーで開いてご覧ください。インターネット接続は不要です。

オリジナルRogueと既存のコードの著作権・ライセンス条件に加え、
JEC版での日本語化・機能追加・アイコンなどの独自の貢献と、
Y.Oz VoxさんのRogue 5.4.5pへの謝辞もLICENSE.TXTに記載しています。
